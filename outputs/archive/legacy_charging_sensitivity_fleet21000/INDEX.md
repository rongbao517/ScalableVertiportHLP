# Legacy charging/discharge-rate sensitivity sweep (archived 2026-07-20)

20 combinations of `charging_rate_per_bin` (c ∈ {3,7,15,25,40} %/bin) ×
`discharge_rate` (d ∈ {0.5,1.0,2.0,3.0} %/km), each a **single-shot**
`run_shanghai_fleet_simulation.py` run against a **fixed** demand bucket
(`--demand-source full_dynspeed`, oracle sites, `vehicles_per_vertiport=700`
→ **fleet=21,000**).

## Why this is archived, not part of current results

- It predates the demand-operations closed-loop equilibrium framework
  (`run_equilibrium_search.py`): demand here is a static input, never fed
  back from wait time -- not directly comparable to any D*/W*/R* result in
  `outputs/fleet_sim/_frozen_baseline_v1/MANIFEST.md`.
- fleet=21,000 is far above the frozen main scenario (fleet=7,500) and the
  "above-knee" sensitivity point (12,000) -- not one of the fleet sizes the
  frozen fleet-size sensitivity conclusion is based on.
- Never reconciled with the unified `t`-numbering / 4-point-window reporting
  convention used everywhere else in the frozen results.

Kept for historical reference only -- do not cite as a current result. If
charging/discharge-rate sensitivity is needed for the final report, it
should be rerun inside the closed-loop framework at fleet=7,500 (the frozen
main scenario), not resurrected from here.

## Contents

- `fleet_sim/` -- all `*_sens_c{c}_d{d}.csv` outputs originally under
  `outputs/fleet_sim/`: `run_summary_`, `time_step_summary_`,
  `assigned_routes_`, `battery_summary_`, `rebalance_log_`,
  `vertiport_assignment_ratio_`, `vertiport_occupancy_`,
  `vertiport_total_count_` (160 files, 20 combos).
- `logs/` -- the corresponding `sens_c{c}_d{d}.log` run logs (18 of 20;
  2 combos' logs were never separately captured, only their outputs).

## Driver script

`scripts/fleet_sim/run_sweep_remaining.sbatch` generated 10 of the 20
combos (`c∈{15,25,40}` × most `d`, plus `c=15,d=2.0/3.0`); the other 10
were generated by an earlier, now-untracked ad-hoc invocation of
`run_shanghai_fleet_simulation.py` with the same tag convention. The
sbatch script has been annotated (2026-07-20) noting this archive and that
its own skip-check will not see files here if rerun.
